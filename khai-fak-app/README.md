# ขายฝาก (ต้นแบบ) — เว็บแอปและแอปมือถือ

ต้นแบบทดลองตามโครงสร้างที่วางไว้ในผังแนวคิด ใช้โค้ดเดียวกันสำหรับ:

- **เว็บแอป (PWA)** เปิดในเบราว์เซอร์ ติดตั้งลงหน้าจอหลักได้
- **แอป iOS / Android** ห่อเว็บแอปด้วย Capacitor (โครงไว้ให้ ยังไม่ได้สร้างไฟล์ native)

> **ยังไม่ใช่บริการจริง** ข้อมูลทั้งหมดเป็นตัวอย่างและเก็บในเครื่องผ่าน localStorage
> ไม่มีการส่งคำขอถึงทีมงาน ไม่มีการยืนยันตัวตนจริง ไม่มีการลงนามสัญญาจริง และไม่มีการชำระเงิน

## สิ่งที่ทำได้ในต้นแบบ

| หน้า | ทำอะไร |
|---|---|
| หน้าแรก `#/` | แยกทางผู้ขายฝากกับนักลงทุน |
| คำนวณ `#/calc` | วงเงิน ยอดไถ่รวม วันครบกำหนด และวันแจ้งเตือน (6 และ 3 เดือนก่อนครบกำหนด) |
| ขอประเมิน `#/apply` | ฟอร์ม 4 ขั้น ตรวจความถูกต้อง ไม่ให้ขอเกินวงเงิน บันทึกเป็นคำขอในเครื่อง |
| ลงทุน `#/deals` | แสดงทรัพย์ตัวอย่างเมื่อยืนยันตัวตนนักลงทุนแล้วเท่านั้น |
| รายละเอียดทรัพย์ `#/deals/:id` | ข้อมูลทรัพย์ตัวอย่าง คำเตือนความเสี่ยง ปุ่มสนใจ |
| สนใจลงทุน `#/invest/:id` | ลงทะเบียนความสนใจ พร้อมกล่องความเสี่ยง |
| บัญชี `#/account` | คำขอของฉัน ความสนใจของฉัน ปุ่มจำลองการยืนยันนักลงทุน ล้างข้อมูล |
| เกี่ยวกับ / ความรู้ | โครงหน้า ยังไม่มีเนื้อหา |

แท็บล่างบนมือถือ: หน้าแรก คำนวณ ขอประเมิน บัญชี และ "ลงทุน" ที่แสดงหลังยืนยันตัวตนนักลงทุนแล้ว
ภาษาไทยเป็นค่าเริ่มต้น สลับเป็นอังกฤษได้จากปุ่มมุมขวาบน

## รันในเครื่อง

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้ง dependency

```bash
cd khai-fak-app
npm start            # เปิด http://localhost:8080
npm test             # ทดสอบการคำนวณ การตรวจความถูกต้อง และ i18n (12 รายการ)
npm run smoke        # ทดสอบในเบราว์เซอร์ (ต้องเปิด npm start ก่อน และมี Playwright ในเครื่อง)
```

## ทำเป็นแอปมือถือ (ขั้นตอนที่ต้องทำบนเครื่องของคุณ)

ขั้นนี้ต้องใช้เครื่องที่มี Xcode (iOS, ต้องเป็น macOS) หรือ Android Studio (Android) และบัญชีนักพัฒนาของ App Store / Google Play

```bash
npm run build:www              # คัดลอก web/ ไป www/
npm install @capacitor/core @capacitor/cli
npx cap add ios                # ต้องใช้บน macOS
npx cap add android
npx cap sync
npx cap open ios               # หรือ android
```

ก่อนส่งเข้าร้านแอป ต้องเปลี่ยน `appId` ใน `capacitor.config.json` จาก `com.example.khaifak` เป็นของคุณเอง

## สมมติฐานที่ต้องยืนยันก่อนใช้จริง

ค่าเหล่านี้อยู่ในโค้ดและต้องให้ทนายหรือบริษัทยืนยัน ห้ามใช้เป็นข้อเสนอจริงก่อนตรวจ

- **สัดส่วนวงเงิน 70%** (`web/js/calc.js`, `LIMIT_RATIO_DEFAULT`) เป็นค่าจากเว็บตัวอย่าง ไม่ใช่นโยบายของบริษัท
- **เพดานดอกเบี้ย 15% ต่อปี** (`MAX_ANNUAL_RATE_PCT`) และ **ระยะ 12 ถึง 120 เดือน** ตามที่รายงานในการค้นคว้า ต้องตรวจกับตัวบท
- **แจ้งเตือนก่อนครบกำหนด 3 ถึง 6 เดือน** (`NOTICE_MONTHS`) ยังไม่ได้ยืนยันจากตัวบท
- **ค่าบริการ** ตั้งเป็น 0 ในเครื่องคิดเลข ให้ใส่ค่าจริงของบริษัท
- **ผลตอบแทนคาดหมายของทรัพย์ตัวอย่าง** (`web/js/data.js`) เป็นตัวเลขสมมติ

## สิ่งที่ยังไม่มีและต้องทำก่อนเปิดให้ใช้จริง

- **Backend:** ยังไม่มีเซิร์ฟเวอร์รับคำขอ ฐานข้อมูล หรือระบบหลังบ้าน การบันทึกอยู่ในเครื่องเท่านั้น
- **การยืนยันตัวตน:** ปุ่มจำลองไม่ได้ตรวจสอบอะไรจริง ต้องทำ OTP และ KYC และตรวจที่มาของเงิน
- **การลงนามและเอกสาร:** ยังไม่มีสัญญาจริงและการลงนามอิเล็กทรอนิกส์ สัญญาต้องให้ทนายตรวจก่อน
- **การชำระเงิน:** ยังไม่มีการรับ-จ่ายเงินทั้งหมด
- **ภาษา:** ในแอปมีไทยและอังกฤษ ยังไม่ได้ใส่ลาว พม่า จีน ญี่ปุ่น อาหรับ และอินโดนีเซียตามที่วางแผนไว้
- **ความเป็นส่วนตัว:** เบอร์โทรและอีเมลถูกเก็บใน localStorage ของอุปกรณ์ ก่อนใช้จริงต้องมีนโยบาย PDPA และการเข้ารหัสและเซิร์ฟเวอร์ที่เหมาะสม
- **การเข้าถึงนักลงทุนต่างชาติ:** ต้องตรวจกฎหมายการชวนลงทุนและการระดมทุนของแต่ละประเทศก่อนเปิดรับ
- **การทดสอบบนอุปกรณ์จริง:** ทดสอบในเบราว์เซอร์แบบมือถือแล้ว แต่ยังไม่ได้ทดสอบบน iOS และ Android จริง

## โครงสร้างโฟลเดอร์

```
khai-fak-app/
├─ web/                 เว็บแอป (ไฟล์ที่ถูกห่อเป็นแอปมือถือ)
│  ├─ index.html
│  ├─ css/styles.css
│  ├─ js/app.js         เราเตอร์และหน้าจอ
│  ├─ js/calc.js        กฎการคำนวณ (ไม่มี DOM)
│  ├─ js/validate.js    ตรวจความถูกต้องของฟอร์ม
│  ├─ js/i18n.js        ข้อความไทย/อังกฤษ
│  ├─ js/data.js        ทรัพย์ตัวอย่าง
│  ├─ js/store.js       localStorage แบบปลอดภัย
│  ├─ sw.js             offline shell
│  └─ manifest.webmanifest, icon.svg
├─ scripts/             serve.js, build-www.js, smoke.mjs
├─ tests/               calc และ validate
└─ capacitor.config.json
```
